# Wordlists

`common.txt` is a small starter list of common passwords. It is not a
substitute for a real wordlist.

For real audits, put `rockyou.txt` (or any wordlist) here or select it in the
cracker GUI with **Browse...**. The GUI defaults to `common.txt` when it exists.

The cracker only runs `aircrack-ng` against captures from networks you own or
are authorized to test.
